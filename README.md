# Data Science Capstone Report

## Overview

This repository contains the final deliverables for the data science capstone project on predicting SpaceX Falcon 9 first-stage landing success. The work covers data collection, cleaning, exploratory analysis, SQL analysis, geospatial visualization, interactive dashboard work, and machine learning model comparison.

## Main Files

- `hands-on_API.ipynb`: SpaceX API data collection and dataset preparation
- `webscraping.ipynb`: Falcon 9 launch data scraping
- `ハンズオンラボデータラングリング.ipynb`: Data cleaning and feature preparation
- `可視化EDAラボ.ipynb`: Exploratory analysis and visualization
- `ピアグレーデッドアサインメント.ipynb`: SQL-based analysis tasks
- `ハンズオンラボFoliumラボ.ipynb`: Launch site map analysis with Folium
- `機械学習予測ラボ.ipynb`: Logistic Regression, SVM, Decision Tree, and KNN comparison
- `Plotly Dash.py`: Interactive dashboard source file
- `データサイエンスキャップストーン最終レポート_全タスク確認版.pdf`: Updated final report with the complete task checklist
- `データサイエンスキャップストーンプレゼンテーション.pdf`: Presentation version of the capstone summary
