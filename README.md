# データサイエンスキャップストーンプロジェクトレポート

## プロジェクト概要

SpaceX Falcon 9の第1段ロケット着陸成功を予測するデータサイエンス・キャップストーンです。SpaceX APIからのデータ取得、データ前処理、探索的データ分析、SQL分析、地理的可視化、機械学習モデル比較、ダッシュボード作成までを実施しています。

## 制作物一覧

- hands-on_API.ipynb: SpaceX APIデータ取得とデータセット構築
- ハンズオンラボデータランングリング.ipynb: データクリーニングと特徴量準備
- 可視化EDAラボ.ipynb: 探索的データ分析と可視化
- webscraping.ipynb: Webスクレイピング
- ピアグレーテッドアサインメント.ipynb: SQLクエリによる分析
- ハンズオンラボFoliumラボ.ipynb: 発射サイトの地図可視化
- 機械学習予測ラボ.ipynb: ロジスティック回帰、SVM、決定木、KNNの比較
